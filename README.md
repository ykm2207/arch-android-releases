# 아치 Android 팀 배포

현재 버전은 **0.3.10-team**이며 버전 코드는 **15**입니다.

기존 앱에서 **계정·설정 → 앱 업데이트 → 업데이트**를 누른 뒤 Android 설치 화면에서 확인하세요. 같은 앱 실행 세션에서는 자동 확인이 6시간 간격으로 동작합니다. 메뉴의 **앱 업데이트**로 바로 확인할 수 있습니다.

홈 화면과 앱 목록에서 아이보리색 아치형 A가 표시됩니다. Android 13 이상에서 런처의 테마 아이콘을 켜면 같은 모양이 테마 색으로 표시됩니다.
