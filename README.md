# 모루 Android 설치

현재 버전: **0.3.8-team** · 버전 코드 13

기존 앱의 **계정·설정 → 앱 업데이트**에서 새 버전을 확인하고 설치하세요. 앱을 삭제하지 않습니다. 자동 확인은 같은 실행 세션에서 6시간 간격으로 제한되며 직접 확인은 즉시 가능합니다. 최초 설치 허용 요청이 나오면 모루(ARCH)의 **이 출처 허용**을 켠 뒤 Android 설치 확인을 진행하세요.

시간표의 교시·학점별 종료 시간, 강의실 표시와 종료된 학기의 문자 성적 입력을 개선했습니다. 기존 추가 수업 시간과 성적을 보존합니다.

[APK 다운로드](https://github.com/ykm2207/arch-android-releases/releases/download/android-team/ARCH.apk) · [전달용 ZIP](https://github.com/ykm2207/arch-android-releases/releases/download/android-team/ARCH.zip) · [배포 정보](update.json)

이 저장소는 설치 파일과 공개 업데이트 정보만 배포합니다. 앱 소스·키·계정 데이터는 포함하지 않습니다.
