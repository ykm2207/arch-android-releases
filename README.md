현재 버전: **0.3.7-team**

기존 ARCH 앱을 삭제하지 않고 APK를 열어 덮어 설치하세요. 기존 일정과 파일은 유지됩니다.
이번 설치 후부터는 **계정·설정 → 앱 업데이트** 또는 앱의 새 버전 안내에서 다운로드·설치할 수 있습니다.
Android가 설치 허용을 요청하면 ARCH의 **이 출처 허용**을 켜고 돌아와 설치를 확인하세요.

이 저장소는 APK와 공개 버전 정보만 배포합니다. 앱 소스와 계정 데이터는 포함하지 않습니다.
