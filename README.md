# 아치 Android 팀 배포

현재 버전은 **0.3.9-team**이며 버전 코드는 **14**입니다.

기존 앱에서 **계정·설정 → 앱 업데이트 → 업데이트**를 누른 뒤 Android 설치 화면에서 확인하세요. 같은 앱 실행 세션에서는 자동 확인이 6시간 간격으로 동작합니다. 메뉴의 **앱 업데이트**로 바로 확인할 수 있습니다.

이번 버전에서는 하단 내 DOT 탭을 정리하고 홈에 출석과 오늘 일정을 나누어 표시합니다. 공유 일정에서 확인 현황과 댓글을 볼 수 있으며, 공유 파일 알림을 누르면 해당 파일이 열립니다.
